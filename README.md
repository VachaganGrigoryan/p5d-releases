# 5D Painting installers

The desktop installers of [5D Painting](https://p5d.notallow.cc), which turns photos into diamond-painting and cross-stitch patterns.

Download the latest version from **[Releases](https://github.com/VachaganGrigoryan/p5d-releases/releases/latest)**, or from the website's [download page](https://p5d.notallow.cc/download).

Each release has `SHA256SUMS.txt` to check a download with `shasum -a 256 -c SHA256SUMS.txt`.

The source code is private. This repository holds only the published installers.
